# رسالة شخصية

موقع ثابت من HTML وCSS وJavaScript. لا يحتاج إلى قاعدة بيانات أو خادم خاص. افتح `index.html` محليًا لمعاينة الواجهة، أو انشر محتويات هذا المجلد على استضافة ملفات ثابتة.

## إعداد EmailJS قبل النشر

1. أنشئ Email service واحدًا في حساب EmailJS واربطه بصندوق البريد الذي سيستقبل الرسائل.
2. أنشئ قالبًا واحدًا للرد المكتوب، ثم خذ Public Key وService ID وTemplate ID.
3. ضع القيم في كائن `EMAILJS` أعلى ملف `app.js` بدل القيم التي تبدأ بـ `YOUR_`.

### Her Message

- `{{message}}` — محتوى مربع الرد الواحد.
- `{{sent_at}}` — وقت الإرسال.

اختيار YES أو NO لا يرسل أي إشعار. يصل البريد فقط عند كتابة رد والضغط على SEND. يجب كتابة الرد في المربع قبل الإرسال. بيانات EmailJS العامة مخصصة للاستخدام في المتصفح؛ قيّد النطاقات المسموح بها من إعدادات EmailJS قبل النشر.
